# Pour Practice

A latte art pour trainer where your phone is the cup.

Hold the phone flat in your cup hand and mime the pour over the screen with an empty pitcher. Pour Practice reads the phone's tilt, coaches the cup motion through each phase of the pour, and scores you against a target tilt for every phase.

## Features

- Heart, tulip and rosetta pour sequences
- Live target tilt for each phase, with a ring that turns green when you're on target
- Voice cues, pitcher instructions, and a wiggle metronome for the rosetta
- After each pour: a tilt chart, a score per phase, and one specific thing to fix
- Learn tempo (1.5× slower) and café speed; 6, 8 and 12 oz cups
- Installable to the home screen; light and dark themes

## Use it

Open the GitHub Pages link on your phone in Safari or Chrome, tap **Enable** next to Motion sensor, then **Calibrate** while holding the phone flat. Use Share → Add to Home Screen to install it.

Motion sensors only work over HTTPS, so the page must be served from GitHub Pages (or another HTTPS host), not opened as a local file.

No real liquid near your phone. Use an empty pitcher.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript, no dependencies)
- `icon.svg`, `icons/`: app icon
- `manifest.webmanifest`: home-screen install metadata
